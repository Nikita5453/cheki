# Бюджет по чекам

Сайт для учёта бюджета по кассовым чекам в гривнах: дата и сумма старта, остаток, расходы по видам затрат и видам продуктов.

Как устроено:

- **Сайт** (`index.html`, `style.css`, `app.js`, `gh.js`) — статический, на GitHub Pages: https://nikita5453.github.io/cheki/
- **Данные** — в приватном репозитории `cheki-data`: `data.json` (бюджет и чеки) и `photos/`. Сайт работает с ним через GitHub API по токену, который вводится в «Настройках» и хранится только в браузере.
- **Распознавание** — `worker/process.py` на компьютере. Берёт чеки со статусом «ждёт распознавания», отдаёт фото Claude Code CLI (`claude -p`, лимиты подписки Claude) и записывает позиции и категории обратно. Запуск: `Распознавание чеков.bat`.

Настройки скрипта через переменные окружения: `CHEKI_MODEL` (`sonnet` по умолчанию, `haiku` экономнее), `CHEKI_INTERVAL` (секунды между проверками, 30), `CHEKI_DATA` (папка с клоном данных, `data/`).
