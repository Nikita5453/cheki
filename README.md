# Бюджет по чекам

Сайт для учёта бюджета по кассовым чекам: дата и сумма старта, остаток, расходы по видам затрат и видам продуктов.
Чек фотографируется, OpenAI распознаёт позиции и категории, перед сохранением всё можно поправить.

- Чистый статический сайт (`index.html`, `style.css`, `app.js`), работает на GitHub Pages.
- Чеки и фото хранятся в браузере (IndexedDB), бюджет и настройки в `localStorage`.
- Ключ OpenAI вводится в «Настройках» на сайте и хранится только в браузере. В репозиторий его не добавлять.
- Перенос между устройствами: «Настройки» → «Скачать резервную копию» / «Загрузить копию».

Локальный запуск: `python -m http.server 8000` в этой папке, затем открыть http://localhost:8000.
